# TvBoost

Android-приложение для телефона: подключается к Android TV / Google TV по Wi-Fi (ADB) и ускоряет его.

- Отключает ненужные приложения (`pm disable-user`), ничего не удаляет; список «Вернуть» восстанавливает всё.
- Системные пакеты, лаунчер, Play-сервисы, настройки защищены и не показываются в списке.
- Ускорение: анимации ×0.5 или выкл., очистка кэша, остановка фоновых процессов.
- Импорт списка `debloat.txt` из репозитория cleanyourtv (папка `examples/<ваш ТВ>/`).

## Сборка APK
**Без Android Studio:** загрузите папку в свой репозиторий на GitHub — вкладка Actions → Build APK → скачайте `app-debug.apk`.
**С Android Studio:** File → Open → папка TvBoost → Run.

## Подключение к ТВ
1. ТВ: Настройки → Устройство → О устройстве → 7 раз «Сборка» → Для разработчиков → «Отладка по USB» (и «Отладка по сети», если есть).
2. Телефон и ТВ в одной Wi-Fi сети, узнайте IP ТВ.
3. В приложении введите IP, нажмите «Подключиться», разрешите отладку на экране ТВ.

Если порт 5555 закрыт, а ТВ предлагает «Беспроводную отладку» с кодом сопряжения — этот режим пока не поддержан.
После работы выключите отладку на ТВ.
